Saat user menjalankan /odin:help, tampilkan teks berikut PERSIS (jangan ubah format atau isi):

## ODIN — Daftar Perintah

| Perintah | Fungsi |
|----------|--------|
| `/odin` | Tampilkan banner ODIN |
| `/odin:help` | Daftar perintah ini |
| `/odin:about` | Penjelasan fitur ODIN dan cara menggunakannya |
| `/odin:status` | Status server: disk, memory, uptime, services |
| `/odin:doctor` | Diagnostik: cek config, koneksi SSH, guard hook, MCP |
| `/odin:check-update` | Cek apakah ada versi ODIN terbaru di GitHub |
| `/odin:setup` | Rekonfigurasi MCP config & guard hook dari dalam sesi |

**Tips**: Setelah `/odin:status`, Anda bisa langsung memberi perintah tentang server — ODIN sudah siap.

Jangan panggil tool MCP apapun. Jangan tambahkan penjelasan lain.
